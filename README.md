# BOOKVERSE — The Living Library

*«Каждая книга — новая вселенная».*

Интерактивная 3D-платформа для чтения: кинематографичное открытие книги, живая библиотека, красивая читалка, умный словарь, бегун на дорожке прогресса и Telegram-бот на общем аккаунте.

Готовы **первый вертикальный срез** и **режим Demo Day** с живым голосованием зала ([инструкция ведущего](docs/DEMO_DAY.md)).

Основной путь пользователя:

Сайт → интро с книгой → библиотека → выбор настоящей книги → перелёт → чтение → клик по слову → сохранение → слово в профиле → сохранённый прогресс → продолжение через Telegram.

Что сделано, что не сделано и что проверено, написано в [docs/STATUS.md](docs/STATUS.md).

## Запуск на Windows 11

Нужен Node.js 22 или новее. Все команды выполняются в папке проекта в PowerShell.

Установка зависимостей (один раз):

```bash
npm install
```

Файл настроек (один раз):

```bash
copy .env.example .env
```

Откройте `.env` и замените `BOT_INTERNAL_SECRET` на длинную случайную строку. Затем создайте базу и загрузите книги, словарь и задания:

```bash
npm run setup
```

### Сайт и сервер вместе

```bash
npm run dev
```

Откройте <http://localhost:5173>. Сервер API работает на порту 4000.

### По отдельности

Сервер:

```bash
npm run dev:server
```

Сайт:

```bash
npm run dev:web
```

Бот (нужен токен, см. ниже):

```bash
npm run dev:bot
```

Бот без Telegram, в консоли:

```bash
npm run bot:sim
```

### Если что-то не запускается

- **Порт занят.** Закройте другой запущенный экземпляр или поменяйте `SERVER_PORT` в `.env`.
- **В каталоге нет книг.** Запустите `npm run content:import`.
- **Сайт просит заново пройти интро.** Это нормально после очистки данных браузера. Пропустить можно кнопкой «Пропустить».

## Настройка Telegram-бота

Сайт работает и без бота. Для настоящего Telegram:

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и username.
2. Скопируйте токен в `.env`: `TELEGRAM_BOT_TOKEN=...`
3. Впишите username без `@`: `TELEGRAM_BOT_USERNAME=...`
4. Перезапустите сервер и запустите бота: `npm run dev:bot`.
5. На сайте: **Моя библиотека → Подключить Telegram**. Ссылка одноразовая и действует 10 минут.

**Важно про адреса.** Telegram не принимает кнопки-ссылки на `localhost` и адреса локальной сети. Пока `PUBLIC_WEB_URL` не публичный HTTPS-адрес, бот отправляет ссылки обычным текстом. Для кнопок на телефоне нужен публичный адрес, например через туннель или хостинг.

### Симулятор

`npm run bot:sim` запускает настоящие обработчики бота с настоящим сервером, но вместо Telegram работает консоль. На сайте нажмите «Подключить Telegram», скопируйте показанную команду `/start link_…` в симулятор, затем пишите `BV-000002`, название книги или текст кнопки меню. Цифра нажимает кнопку из последнего сообщения.

Симулятор нужен для проверки логики. Это не Telegram, и на нём нельзя проверить доставку сообщений.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сайт и сервер в режиме разработки |
| `npm run build` | проверка типов и сборка сайта |
| `npm run start` | сервер и собранный сайт |
| `npm run test` | юнит-тесты, тесты API и бота |
| `npm run test:e2e` | браузерные сквозные тесты |
| `npm run lint` | ESLint |
| `npm run content:import` | загрузка книг, словаря и заданий |
| `npm run perf` | замер FPS собранного сайта на настоящей видеокарте |

## Устройство проекта

```
apps/web                 сайт: React, Three.js, GSAP, читалка
apps/server              API: Fastify, Prisma, Socket.IO
apps/bot                 Telegram-бот на Telegraf
packages/shared          схемы, типы, Book ID, темы
packages/reading-engine  позиции, покрытие, разбивка на страницы
packages/game-engine     уровни, достижения, интервальное повторение
content                  книги, словарь, задания
docs                     документация
e2e                      браузерные тесты
```

Как устроены книги, словарь, темы и награды: [docs/GUIDE.md](docs/GUIDE.md). Сценарий выступления: [docs/PRESENTATION.md](docs/PRESENTATION.md). Режим показа: [docs/DEMO_DAY.md](docs/DEMO_DAY.md). Как добавить книгу: [content/README.md](content/README.md).

## Книги и права

Каталог содержит только проверенные тексты: пять произведений в общественном достоянии (оригиналы, без переводов) и одну оригинальную повесть, написанную для проекта. Источник и обоснование указаны в файле `book.json` каждой книги и на карточке книги на сайте.
