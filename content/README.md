# Как добавить книгу

Каждая книга лежит в своей папке `content/books/<slug>/`.

| Файл | Обязателен | Что внутри |
|---|---|---|
| `book.json` | да | название, автор, язык, жанр, описание, обложка, лицензия |
| `text.txt` | да | текст книги |
| `notes.json` | нет | пояснения к конкретным местам |
| `quiz.json` | нет | задания к главам |

После изменений выполните `npm run content:import`. Импорт можно запускать сколько угодно раз.

## Формат текста

```
# Глава первая. Название главы

Абзац идёт одной строкой.

Следующий абзац отделён пустой строкой.

~

> Строка стихотворения
> Следующая строка
```

- `# ` начинает главу. Если заголовков нет, вся книга считается одной главой.
- `~` ставит орнамент-разделитель.
- `> ` отмечает строку стиха. Подряд идущие строки автоматически делятся на блоки.

Исходники Викитеки и Project Gutenberg можно преобразовать так:

```bash
node content/tools/wiki2text.mjs wiki исходник.wiki content/books/slug/text.txt
```

Для стихов добавьте `--verse`, для обрезки приложений `--cut "Заголовок"`, для Gutenberg используйте режим `gutenberg`.

## Права проверяются до добавления

1. Перевод и оригинал проверяются **отдельно**. Старый автор не означает свободный перевод.
2. Срок охраны зависит от страны. Для безопасности ориентируйтесь на «жизнь автора + 70 лет».
3. В `book.json` укажите источник, ссылку, дату проверки и обоснование.
4. Если права подтвердить нельзя, книгу не добавляйте.

## Book ID

Коды закреплены в `content/registry.json`. Импорт дописывает новые книги в конец и никогда не меняет существующие номера. Не редактируйте выданные номера: коды могут быть уже напечатаны или сохранены у читателей.

Импорт заменяет блоки книги. Ключи абзацев вида `c2-p0014` зависят от порядка абзацев, поэтому при правке текста уже опубликованной книги добавляйте абзацы в конец главы, иначе закладки и прогресс читателей могут сдвинуться.

## Словарь

Статьи лежат в `content/glossary/ru.json` и `en.json`. Лемма записывается в начальной форме: существительное в именительном падеже, глагол в инфинитиве, прилагательное в мужском роде. Определения пишутся своими словами простым языком: копировать чужие словари нельзя.

Пояснение в `notes.json` привязано к месту через `match`: это точный фрагмент текста из абзаца. Если фрагмент не найден, импорт сообщит об этом.

## Задания

В `quiz.json` каждая миссия относится к главе. Типы заданий: `single` (выбор ответа), `order` (порядок событий), `match` (соединить пары). Ответы хранятся только на сервере. Добавляйте вопросы, проверенные человеком.
