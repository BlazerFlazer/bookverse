# Живая библиотека

Система атмосферы BOOKVERSE: дождь на окнах, четыре части суток, синтезированные звуки, настройки в аккаунте и управление залом из Telegram и с экрана ведущего.

## Как запустить

Новых сервисов и ключей не нужно. После обновления кода примените миграцию и запустите сайт как обычно:

```bash
npm run db:setup
```

```bash
npm run dev
```

Звуки и вид за окном создаются прямо в браузере, поэтому аудиофайлов и новых картинок в проекте нет. Новых переменных окружения тоже нет: для ведущего в Telegram достаточно уже настроенного бота.

## Из чего состоит

| Модуль | Что делает |

| `apps/web/src/atmosphere/AtmosphereManager.ts` | единственный хозяин атмосферы: время суток, дождь, молнии, звук. Работает и без WebGL |
| `apps/web/src/atmosphere/TimeOfDayController.ts` | плавный путь к нужной точке суток, кратчайшей дугой |
| `apps/web/src/atmosphere/keyframes.ts` | палитры четырёх частей суток |
| `apps/web/src/atmosphere/lighting.ts` | общий свет зала: один набор значений на все материалы |
| `apps/web/src/atmosphere/AmbientAudioManager.ts` | слои звука на Web Audio |
| `apps/web/src/atmosphere/mix.ts` | чистая формула громкостей: приглушение при чтении и под озвучку |
| `apps/web/src/atmosphere/store.ts` | настройки, браузер, аккаунт, перенос настроек гостя |
| `apps/web/src/world/library/rainGlass.ts` | шейдер мокрого стекла |
| `apps/web/src/world/library/RainWindows.tsx`, `Fireplace.tsx` | окна, ниша со скамьёй, камин |
| `apps/web/src/ui/AtmospherePanel.tsx`, `FlatAtmosphere.tsx` | панель настроек и плоский режим |
| `apps/web/src/demo/DemoAtmospherePanel.tsx` | кнопки ведущего и слежение за показом |
| `apps/server/src/atmosphere/` | хранение настроек в аккаунте |

Новая атмосфера вроде снежной библиотеки добавляется так: значение в `ATMOSPHERE_PRESETS`, своя таблица палитр в `keyframes.ts` и свой шейдер осадков. Менеджер, панель, звук, бот и показ менять не нужно.

## Как устроено время суток

Положение на круге: 0 утро, 1 день, 2 вечер, 3 ночь, у 4 круг замыкается.

- **Быстрые сутки** (по умолчанию): полный круг за 24 минуты, по шесть минут на часть суток. Положение считается от абсолютного времени, поэтому сайт и бот называют одно и то же, не обмениваясь сообщениями.
- **По часам:** середина утра в 9:00, дня в 14:00, вечера в 19:00, ночи в 1:00. Бот учитывает часовой пояс, который сайт сохраняет вместе с настройками.
- **Вручную:** зал идёт к выбранной части суток кратчайшей дугой и проходит промежуточные состояния. Сцена не перезагружается.
- **На показе:** «Сутки по кругу» проходят всё за 80 секунд.

## Где хранятся настройки

| Кто | Где |
|---|---|
| Гость | в браузере, ключ `bv.atmosphere` |
| Аккаунт | таблица `AtmospherePreference`, все поля из раздела 15 задания |
| Гость зарегистрировался | настройки браузера переносятся в аккаунт сразу |
| Вход в аккаунт с настройками | главными становятся настройки аккаунта |

Изменения данных: модель `AtmospherePreference`, поля `atmosphere` и `presenterTelegramId` у показа, модель `PresenterLinkToken`, миграция `20261102040915_living_library`.

## Качество эффектов

«Авто» выбирает уровень по видеокарте. Если на нижней границе разрешения кадры всё равно проседают, «Авто» убирает слой капель, а когда кадры выравниваются, возвращает его. Качество, выбранное вручную, не трогается.

| | Низкое | Среднее | Высокое | Ультра |
|---|---|---|---|---|
| Слои капель | 1 | 2 | 3 | 3 |
| Окон галереи на сторону | 2 | 4 | 5 | 5 |
| Косые лучи из окон | нет | нет | да | да |
| Кадров за читалкой | 0,5 | 10 | 15 | 24 |
| Звук | постоянные слои | все слои | все слои | все слои |
| Предел плотности пикселей | 0,85 | 1 | 1,5 | 2 |

Если WebGL недоступен, работает плоская версия: арочное окно с дождём на обычном холсте, те же время суток и звук, каталог и чтение полностью.

## Что слышно

| Слой | Когда |
|---|---|
| Ровный дождь и шипение капель | всегда, сила зависит от настройки дождя |
| Тон комнаты | всегда, ночью сильнее |
| Отдельные капли по стеклу | случайно, не на низком качестве |
| Камин | вечером и ночью, не на низком качестве |
| Скрип дерева | раз в 1–2 минуты, очень тихо |
| Далёкий гром | вечером и ночью, раз в 3–6 минут, при чтении реже |

Звук начинается только после первого нажатия или клавиши: так требует браузер. Значок динамика вверху отключает весь звук сайта, панель управляет только атмосферой. В книге громкость падает почти вдвое, а верхние частоты срезаются. Пока книгу читает голос, дождь уходит ещё дальше. В скрытой вкладке звука нет.

Молнии выключены по умолчанию: даже мягкое мерцание подходит не всем. При «Меньше движения» вспышек нет совсем, в том числе на показе.

## Команды бота

Новый пункт меню **🏛 Живая библиотека** и команда `/atmosphere`.

| Кто | Что доступно |
|---|---|
| Любой | текущая атмосфера и время суток, ссылка на библиотеку и на текущее время суток |
| С привязанным аккаунтом | свои настройки и сохранение: «Автоматически», «Утро», «День», «Вечер», «Ночь». Открытый сайт меняется сразу |
| Ведущий | «Показать дождливое утро», «Показать день», «Показать вечер», «Показать ночь», «Сутки по кругу», «Включить атмосферу», «Усилить дождь», «Показать погоду» |

Ссылка вида `/?atmosphere=evening` показывает выбранное время суток, но не меняет настройки читателя.

### Как подключается ведущий

1. На сайте войдите ключом ведущего и начните показ.
2. Откройте «Сценарий показа» и нажмите «Подключить Telegram ведущего».
3. Перейдите по ссылке или отправьте боту команду `/presenter КОД`.

Ссылка одноразовая, живёт 10 минут, в базе хранится только её хеш. Подключение действует до конца показа и стирается вместе с ним. Секрет бота подтверждает лишь то, что запрос пришёл от бота: право управлять экраном есть только у Telegram, подключённого этой ссылкой.

## Управление на показе

Кнопки находятся в панели «Сценарий показа» на любой странице:

| Кнопка | Что делает |
|---|---|
| Утро, День, Вечер, Ночь | плавно переводит зал |
| Сутки по кругу | полный круг за 80 секунд |
| Обычный режим | возвращает настройки ведущего |
| Сильный дождь | усиливает дождь и его звук |
| Звуки включены | включает и выключает атмосферу |
| Показать погоду | сильный дождь на 14 секунд, вспышка и гром |
| Подойти к окну | камера у капель на стекле |
| Открыть книгу | книга вылетает с полки из дождливого зала |
| Подключить Telegram ведущего | одноразовая ссылка |

В репетиции есть «Имитация Telegram»: команды идут через сервер и подписаны на экране как имитация. Настоящий бот без токена проверяется консольным симулятором `npm run bot:sim`.

## Как проверить смену суток

1. Откройте библиотеку и нажмите значок облака вверху.
2. Выберите «Ночь»: за несколько секунд зал пройдёт через промежуточные состояния.
3. Нажмите «К окну», затем «К камину».
4. Откройте книгу и закройте её: звук станет тише и вернётся.

Текущее состояние можно посмотреть в консоли браузера:

```js
window.__bookverseAtmosphere()
```

Ответ содержит точку суток, силу дождя, слои, состояние звука и громкости. Секретов и данных читателя в нём нет.

## Ограничения

- **На Vercel нет сокетов.** Сайт, зал, звук и настройки работают, но бот на Vercel не запущен, а сохранение в Telegram не меняет открытую страницу сразу. Живое управление показом работает при локальном запуске.
- **Капли условные.** На дальних окнах они крупнее настоящих, иначе их не видно с такого расстояния.
- **Вид за окном общий.** Он собран из одной текстуры масок, поэтому это один пейзаж с разных точек.
- **Отражения поддельные.** На полу и столе это мягкие пятна света, а не настоящие зеркала.
- **Звук синтезирован.** На слух его должен оценить человек: автотесты проверяют уровни, а не красоту.
