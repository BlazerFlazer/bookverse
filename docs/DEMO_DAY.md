# Demo Day: инструкция ведущего

Режим показа работает на странице `/demo`. Голоса настоящие: каждое число на экране это действие живого зрителя. Исключение одно, репетиция, и она помечена на всех экранах.

## Подготовка

1. В `.env` задайте ключ ведущего:

   ```
   DEMO_PRESENTER_KEY=придумайте-длинный-ключ
   ```

   Пока ключ пуст, режим ведущего выключен.

2. Запустите сайт:

   ```bash
   npm run dev
   ```

3. Подключите компьютер и телефоны зрителей к **одной** сети Wi-Fi.
4. Откройте <http://localhost:5173/demo> и введите ключ.
5. Нажмите **Репетиция** и проверьте QR-код своим телефоном.

### Если телефон не открывает QR-код

- Сервер сам подставляет адрес компьютера в сети. Если он определился неверно, укажите его вручную в `.env`, например `DEMO_PUBLIC_URL=http://192.168.1.11:5173`, и перезапустите сервер.
- Брандмауэр Windows может блокировать входящие подключения. При первом запуске разрешите Node.js доступ к частной сети.
- Школьный Wi-Fi может запрещать устройствам видеть друг друга. Тогда раздайте сеть с телефона или используйте публичный адрес.
- При запуске с `NODE_ENV=production` укажите адрес сети в `PUBLIC_WEB_URL`, иначе запросы с телефонов будут отклонены.

## Управление

| Кнопка | Что делает |
|---|---|
| **Начать показ** | создаёт зал с кодом и QR, зрители только настоящие |
| **Репетиция** | то же, но можно добавить имитированных участников, на всех экранах есть пометка |
| **Голосование за книгу** | открывает голосование за четыре рекомендованные книги |
| **Вопрос залу** | открывает вопрос из проверенных заданий к книгам |
| **Закрыть и показать итог** | закрывает приём ответов, показывает победителя или верный ответ с разбором |
| **Открыть «Книга»** | возвращается в зал и открывает победителя настоящей анимацией |
| **Вихрь страниц** | разрешённая анимация в зале |
| **Финал** | финальная сцена, зрители видят благодарность |
| **Сброс** | удаляет голоса и участников, код зала остаётся |
| **Завершить** | закрывает показ и удаляет данные участников |

Клавиши: `H` скрывает панели, `F` включает полный экран.

**Сценарий показа** в правом нижнем углу виден только ведущему на всех страницах и переключает шесть этапов показа.

Если страница случайно обновилась, показ не пропадёт: сервер хранит его состояние, и экран вернётся туда же. Открытое голосование тоже сохранится.

## Для зрителей

- **QR-код.** Открывается лёгкая страница без 3D, она работает на любом телефоне.
- **Код вручную.** Страница `/join`, код показан на экране.
- **Telegram.** Если бот запущен, зрители пишут ему `/demo КОД` и отвечают кнопками. На экране появляется эта подсказка. Сайт работает и без бота.

Регистрация и личные данные не нужны. Каждый зритель получает случайный псевдоним вроде «Смелый Лис». Настоящие имена на экран не попадают, а свободного ввода текста нет, поэтому зрители не могут написать на экране что-либо лишнее.

Голос один на устройство: обновление страницы не даёт проголосовать повторно. Один человек с двумя телефонами проголосует дважды, для школьного показа это допустимо.

## Что происходит с данными

Во время показа сервер хранит псевдонимы, голоса и Telegram ID участников, подключившихся через бота. После **Завершить** или **Сброс** это удаляется. После завершения остаются только итоговые числа.

Правильный ответ не покидает сервер, пока вопрос открыт: его нельзя найти в браузере ни у зрителя, ни на проекторе.

## Тестовый прогон перед показом

За день до выступления:

1. Запустите **Репетицию**, нажмите **Ещё 10 участников**, проведите голосование и вопрос.
2. Откройте зал с настоящего телефона и проголосуйте.
3. Откройте книгу-победителя и пройдите все шесть этапов через **Сценарий показа**.
4. Нажмите **Завершить**, а перед выступлением запустите **Начать показ**.
